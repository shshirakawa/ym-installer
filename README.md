# YMI — Yandex Music Installer

Автоустановщик и менеджер обновлений Яндекс Музыки для Arch Linux, CachyOS и других Arch-based дистрибутивов.

**Автор:** [Sh.Shirakawa](https://shshirakawa.com)
**Лицензия:** MIT

---

## Установка утилиты

```bash
git clone https://github.com/shshirakawa/ym-installer.git
cd ym-installer
./ymi -m install
```

После этого команда `ymi` доступна из любого места в терминале.

---

## Команды

| Команда | Описание |
|---|---|
| `ymi install` | Установить Яндекс Музыку |
| `ymi check` | Проверить версию |
| `ymi update` | Обновить |
| `ymi delete` | Удалить |
| `ymi launch` | Запустить |
| `ymi -m install` | Добавить `ymi` в систему |
| `ymi -m delete` | Убрать `ymi` из системы |

---

## Как это работает

1. Получает актуальную версию из облачного манифеста Яндекса.
2. Скачивает официальный `.deb` и проверяет целостность по `sha512`.
3. Упаковывает в нативный Arch-пакет (`.pkg.tar.zst`) и ставит через `pacman`.
4. При удалении `pacman -Rns` стирает все файлы без остатка.

Сборка происходит в `/tmp` — после установки временные файлы уничтожаются автоматически.

## Требования

- Arch Linux / CachyOS / Arch-based дистрибутив
- Архитектура: `x86_64`
- Пакеты: `base-devel`, `curl`
